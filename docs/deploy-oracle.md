# Выкладка на Oracle Cloud Always Free

Дополнение к [deploy.md](deploy.md), а не замена. Порядок действий с
четвёртого шага там же и остаётся: код, сайт, ML-сервис, службы, Caddy.
Здесь только то, чем Oracle отличается от обычного VPS, — и отличий ровно
четыре: как получить машину, два межсетевых экрана вместо одного, ARM
вместо x86 и что тут считается «бесплатным».

## Зачем вообще

В deploy.md посчитано, что нужно 4 ядра и 8 ГБ памяти, и выбран netcup за
€10,37 в месяц. Oracle в бесплатном тарифе даёт **4 ядра ARM и 24 ГБ** —
втрое больше памяти, чем нам нужно, и бессрочно.

Ловушки, из-за которых это не «бесплатный сыр без условий», перечислены в
конце. Прочитайте их до того, как переносить туда рабочий стенд.

## 1. Машина

Тариф — **VM.Standard.A1.Flex**, форма Ampere ARM. В бесплатный предел
входит суммарно 4 OCPU и 24 ГБ памяти: можно взять одну машину со всем
сразу, что нам и нужно — три службы живут рядом.

- Образ: **Canonical Ubuntu 24.04** (сборка aarch64, она подставится сама).
- OCPU 4, память 24 ГБ.
- Загрузочный том 100–200 ГБ. Бесплатный предел на блочные тома — 200 ГБ
  на весь аккаунт, и это единственное место, где легко выйти за него.
- Ключ SSH — свой, пароль Oracle не заводит.

**«Out of host capacity» — это норма, а не поломка.** Ampere в популярных
регионах разобрана, и создание машины отвечает отказом. Что помогает, по
убыванию толка:

1. **Перевести аккаунт в Pay As You Go.** Бесплатные ресурсы при этом
   остаются бесплатными и продолжают считаться по тем же пределам, но
   очередь на выдачу становится другой, и машина обычно создаётся сразу.
   Это же снимает риск из последнего раздела.
2. Пробовать другие домены доступности (AD-1, AD-2, AD-3) в своём регионе.
3. Повторять с перерывом в несколько часов.

Регион менять после регистрации нельзя — домашний регион выбирается один
раз. Берите европейский: проект финансируется по линии ЕС, и юрисдикция
хранения тут не формальность (в deploy.md об этом уже сказано).

**Сделайте адрес постоянным.** По умолчанию публичный IP эфемерный и
меняется при остановке машины — домен после первой же перезагрузки станет
показывать в пустоту. Networking → IP Management → Reserved Public IP,
затем прикрепить его к машине.

## 2. Два межсетевых экрана

Это главная причина, по которой «всё поставил, а сайт не открывается».
Oracle фильтрует трафик **дважды**, и оба места надо открыть.

**Снаружи — Security List облака.** Networking → VCN → Subnet → Security
List → Add Ingress Rules. Два правила, Source `0.0.0.0/0`, TCP, порты
`80` и `443`.

**Внутри — iptables самой машины.** Образы Oracle приезжают с правилами,
которые роняют всё, кроме SSH. Одного облачного правила мало: пакет
дойдёт до машины и там же умрёт молча.

```bash
sudo iptables -I INPUT 6 -p tcp --dport 80  -j ACCEPT
sudo iptables -I INPUT 6 -p tcp --dport 443 -j ACCEPT
sudo netfilter-persistent save
```

Без `netfilter-persistent save` правила живут до перезагрузки — и стенд
отвалится ночью, когда никто не поймёт почему.

Порты 3000 и 8000 не открывайте нигде. Сайт слушает петлю, ML-сервис тем
более: у него нет ни пароля, ни счётчика запросов, и открытый наружу
восьмитысячный означает, что ваш ключ OpenAI тратит кто угодно.

## 3. ARM вместо x86

Всё, что перечислено в deploy.md, под aarch64 есть и ставится теми же
командами: Node 22 из NodeSource, Python 3.12, Caddy, `npm ci`.

Отличается один пункт — **PyTorch для ML-сервиса**. Колёса под aarch64 на
PyPI есть, но ставятся дольше и тянут больше зависимостей, чем на x86.
Ставьте версию для процессора явно, иначе pip потащит сборку с поддержкой
видеокарты, которой тут нет:

```bash
cd /srv/mediamap/ml
python3.12 -m venv .venv
.venv/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/bin/pip install -r requirements.txt
```

Модель NLLB от архитектуры не зависит — те же 2,4 ГБ, та же команда
`scripts/fetch_translator.py` из deploy.md.

Считает ARM-ядро перевод примерно как x86: разница в пределах погрешности,
на глаз не видна.

Файлы служб и Caddyfile из `deploy/` переносить не нужно — в них нет
ничего, привязанного к архитектуре.

## 4. Проверка

После шагов 3–7 из deploy.md:

```bash
curl -s localhost:8000/health            # ML-сервис
curl -si localhost:3000/ru | head -1     # сайт
curl -sI https://mediamap.kg | head -1   # снаружи, через Caddy
free -h                                  # ML-сервис займёт ~3 ГБ
```

Если первые два отвечают, а третий нет — дело в разделе 2, и почти всегда
в iptables, а не в облачном правиле.

## Что тут считается бесплатным

| | Предел Always Free |
|---|---|
| Ampere ARM | 4 OCPU и 24 ГБ памяти суммарно |
| Блочные тома | 200 ГБ на аккаунт |
| Исходящий трафик | 10 ТБ в месяц |
| Резервный публичный IP | 1 штука |

Нам этого хватает с запасом: по расчёту из deploy.md в работе занято около
3,5 ГБ памяти и 5 ГБ диска.

## Чего ждать неприятного

**Простаивающие машины отбирают.** У аккаунтов, оставшихся чисто
бесплатными, Oracle вправе забрать простаивающую Always Free машину —
критерий примерно «меньше 20% загрузки процессора неделю». Демонстрационный
стенд, который открывают раз в месяц, под это описание подходит идеально.
Перевод аккаунта в Pay As You Go снимает и это: бесплатные ресурсы остаются
бесплатными, но изъятию не подлежат. Карту при этом всё равно спросят.

**Карта нужна при регистрации.** Списывают около доллара на проверку и
возвращают.

**Аккаунт можно потерять целиком.** Oracle известен внезапными блокировками
на этапе проверки при регистрации, без внятного объяснения. Поэтому
резервная копия с этой машины должна уезжать **наружу**, а не лежать рядом:

```bash
# в cron, ежедневно — как в deploy.md, но с отправкой на сторону
tar czf /var/backups/mediamap-$(date +%F).tgz \
    /srv/mediamap/web/prisma/dev.db /srv/mediamap/web/uploads
```

Базу и `uploads/` не восстановить ниоткуда: публикацию, о которой сообщил
заявитель, к моменту проверки часто уже удаляют, и снимок остаётся
единственным свидетельством.

**Переезд обратно ничего не стоит.** Всё лежит в двух местах — файл базы и
папка вложений, — и переносится на любой обычный VPS по deploy.md как есть.
Это и есть главный довод в пользу «попробовать бесплатно»: если Oracle
разонравится, потеряете вечер, а не проект.
