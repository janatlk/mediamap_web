# Второй проект: мониторинг кыргызских источников — оценка

_17.10.2026. Оценка для заявки: что входит, где трудности, сколько людей,
денег и времени просить._

Задача: собирать публикации кыргызских источников и отбирать их по
ключевым словам на кыргызском и русском, причём слово должно находиться во
всех формах — «маалымат» должно ловить «маалыматтарды», «китеп» —
«китеби».

---

## Что уже есть и что из этого берём

В mediamap.kg работает дайджест (`src/server/news-collect.ts`): раз в час
обходит RSS-ленты, отбирает заметки по словам, складывает в базу,
показывает в панели, где что сломалось. Отбор идёт по началу слова, и для
кыргызского это уже неплохо — язык прибавляет только суффиксы, приставок в
нём нет.

Чего в нём нет и что составляет новый проект:

- **Источники без RSS.** Кыргызоязычных лент почти нет — в стартовом
  наборе дайджеста она одна (24.kg). Остальное придётся разбирать со
  страниц сайтов, по разборщику на сайт.
- **Полный текст, а не заголовок.** Дайджест смотрит заголовок и анонс.
  Мониторинг должен искать по телу статьи.
- **Настоящая морфология.** Поиск по началу слова пропускает чередования
  на стыке основы и суффикса (подробно ниже) и ловит лишнее у коротких
  основ.
- **Обход блокировок.** Дайджест ходит с одной машины в Германии. Для
  кыргызских сайтов этого мало.

Переиспользуем: схему панели и вход, ML-сервис (проверка спорных
совпадений моделью, перевод ky→ru для проверяющих через уже развёрнутый
NLLB), подход к журналу ошибок по источникам.

**Рекомендация по устройству:** отдельный сервис на Python со своей базой
Postgres, а интерфейс — новым разделом в существующей панели. Python здесь
не вкусовщина: разбор страниц (trafilatura), морфология русского
(pymorphy3), кыргызский анализатор (Apertium, HFST), Telegram (Telethon)
есть только там или там сильно зрелее.

---

## Блокировки — да, и в обе стороны

Проверка 17.10.2026 с зарубежного адреса:

| Сайт | Ответ |
|---|---|
| azattyk.org, kg.akipress.org, knews.kg, super.kg, ktrk.kg, kabar.kg, kaktus.media | открываются |
| gov.kg, aprel.kg | соединение не установлено |
| t.me/s/… (веб-превью каналов) | для проверенных каналов перенаправляет на обычную страницу без постов |

Отсюда три разных проблемы:

1. **Сайты, закрытые для заграницы.** Государственные ресурсы и часть
   региональных отвечают только кыргызским адресам или отвечают так
   медленно, что обход срывается. Нужна точка выхода в КР — небольшой VPS у
   кыргызского провайдера, через который идут запросы к таким сайтам.
2. **Сайты, закрытые внутри КР.** Издания, заблокированные в Кыргызстане,
   с кыргызского адреса не откроются. Значит, точки выхода нужны **две** —
   в ЕС и в КР, — и у каждого источника в настройке указано, через какую
   ходить. Отдельно: собирать и показывать материалы изданий, признанных в
   КР экстремистскими, может быть уголовно рискованно для местной
   организации. Список источников надо согласовать с заказчиком и юристом
   до разработки, а не после.
3. **Защита от роботов.** Cloudflare, ограничение частоты, страницы,
   которые собираются скриптом в браузере. Лечится вежливой частотой
   обхода, кэшем и безголовым браузером (Playwright) там, где без него
   никак. Безголовый браузер — это 300-500 МБ памяти на экземпляр, поэтому
   только для тех сайтов, которым он действительно нужен.

Отдельно — **Sputnik**: технически открывается, но в ЕС его материалы под
санкциями, а проект на европейских деньгах. Брать или нет — вопрос к
донору, не к разработчику.

### Соцсети — честно

Большая часть кыргызской повестки живёт не на сайтах, а в Telegram,
Facebook, Instagram и TikTok. Здесь разница огромная:

- **Telegram** — реально. Публичные каналы читаются через API
  (Telethon) от имени обычной учётной записи. Нужен отдельный номер
  телефона, и учётку могут ограничить за частые запросы — закладываем
  умеренный темп. Веб-превью `t.me/s/` проще, но у части каналов отключено.
- **YouTube** — реально, официальный API с бесплатной квотой.
- **Facebook и Instagram** — нет. CrowdTangle закрыт в августе 2024-го,
  Meta Content Library выдаётся исследователям по заявке, рассмотрение
  месяцами. Сбор со страниц нарушает правила Meta и кончается блокировкой.
- **TikTok** — Research API открыт исследователям из США и Европы;
  кыргызской организации, скорее всего, не дадут.

Предлагаю в заявке: сайты + Telegram + YouTube. Facebook — отдельным
пунктом «подать заявку в Meta Content Library», без обещания результата.

## Морфология

### Русский

Решено давно: pymorphy3 приводит и ключевое слово, и текст к начальной
форме, сравниваем начальные формы. Поиск по началу слова ломается на
чередованиях: «ложь» → «лжи», «враг» → «вражеский». Лемматизация это
снимает. 2-3 дня работы.

### Кыргызский

Готового инструмента уровня pymorphy для кыргызского нет. Есть Apertium
(`apertium-kir`) — анализатор на конечных автоматах, но насколько он
покрывает новостной язык, надо мерить на нашем корпусе.

Хорошая новость: грамматика кыргызского очень регулярна, а ключевых слов
у нас десятки, не тысячи. Поэтому основной путь — **порождать все формы
каждого ключевого слова по правилам**, а не разбирать каждое слово
текста:

- **Гармония гласных.** Суффикс принимает один из четырёх видов:
  -лар/-лер/-лор/-лөр, -дар/-дер/-дор/-дөр, -тар/-тер/-тор/-төр — по
  последнему гласному основы.
- **Уподобление согласных.** После глухого — т-, после звонкого — д-,
  после гласного — л-: «маалымат-тар», «сөз-дөр», «китеп-тер».
- **Озвончение на стыке.** «китеп» → «китеби», «жүрөк» → «жүрөгү». Поиск
  по началу слова этого не находит — «китеп» не начало слова «китеби».
- **Выпадение гласного.** «мурун» → «мурду», «орун» → «орду».
- **Порядок суффиксов.** Множественное число → принадлежность → падеж:
  «маалымат-тар-ы-н-ан». Для существительного это сотня-полторы форм —
  перебрать их в коде дёшево.

Дополнительно:

- **Небрежное написание.** В соцсетях и комментариях ң, ө, ү часто
  пишут как н, о, у, иногда латиницей. Сопоставлять надо и по точному
  написанию, и по «сложенному».
- **Слишком короткие основы.** «жал» поймает и «жалган», и «жалпы».
  Панель должна показывать сгенерированные формы и примеры совпадений
  из уже собранного, прежде чем слово включится.
- **Спорные совпадения** отдаём модели ML-сервиса на подтверждение — так
  же, как сейчас оцениваются заявки.
- **Глаголы.** Парадигма глагола сложнее существительного (время, лицо,
  залог, отрицание). Для первой версии — основные формы; полную парадигму
  делаем, если ключевые слова-глаголы окажутся заказчику важны.

Без носителя языка тут не обойтись: нужен лингвист-консультант, который
проверит правила и разметит проверочный набор. 15-25 часов.

### Как поймём, что работает

Размечаем руками 300-500 статей (кыргызских и русских): где тема есть, где
нет. Меряем, сколько нашли (полнота) и сколько нашли лишнего (точность).
Цель первой версии — полнота не ниже 90% при точности не ниже 80% на этом
наборе. Без такого замера «склонение работает» — это слова.

## Прочее, что съедает время

- **Повторы.** Одна новость перепечатывается десятком сайтов. Склеиваем
  по сходству текста, иначе лента — это одно и то же десять раз.
- **Определение языка.** На смешанных сайтах язык ленты неизвестен.
  Кыргызский выдают буквы ң, ө, ү; для коротких текстов — fastText
  (lid.176 знает кыргызский).
- **Поддержка разборщиков.** Сайты меняют вёрстку несколько раз в год, и
  разборщик молча начинает отдавать ноль статей. Нужен сигнал «источник
  ничего не дал за сутки» — в дайджесте он уже есть, перенесём.
- **Объём.** 30-50 источников дают порядка 3-10 тысяч материалов в сутки.
  С полным текстом это десятки гигабайт в год — SQLite здесь уже не
  годится, отсюда Postgres. Для поиска — свой столбец с нормализованными
  словами: встроенного кыргызского словаря в Postgres нет.

## Ресурсы

### Люди

| Кто | Объём |
|---|---|
| Разработчик (сборщик, морфология, панель) | основная работа, см. сроки |
| Лингвист-консультант, носитель кыргызского | 15-25 часов |
| Заказчик: список источников, ключевые слова, приёмка | 3-5 дней суммарно |

### Деньги в месяц

| Что | Ориентир |
|---|---|
| Отдельный VPS под сборщик и Postgres (4 ядра, 8 ГБ, NVMe; как у основного сайта) | €10-15 |
| Точка выхода в КР — малый VPS у кыргызского провайдера | $10-30, цену уточнить у местных |
| Номер телефона под Telegram-учётку | копейки |
| Модель для проверки спорных совпадений | $20-50 при нескольких тысячах проверок в месяц |
| **Итого** | **около $50-100 в месяц** |

Безголовый браузер и прокси с «жилыми» адресами — только если
обнаружатся сайты, которые иначе не открываются. Кыргызских «жилых»
адресов у прокси-сервисов мало, и стоят они по трафику — закладывать
заранее не стоит.

## Сроки

Рабочие дни одного разработчика.

| Этап | Дней |
|---|---|
| Обследование: список источников с заказчиком, проверка каждого из ЕС и из КР, тип (RSS / страница / скрипт / заблокирован / Telegram) | 3-5 |
| Основа: сервис, Postgres, расписание, очередь, повторы, две точки выхода, журнал ошибок по источникам | 5-7 |
| Источники: общий RSS, разборщики сайтов (~20 по 0,5-1 дня), безголовый браузер для трудных, Telegram, YouTube | 16-29 |
| Русская морфология | 2-3 |
| Кыргызская морфология: порождение форм, нормализация написания, сверка с Apertium, проверка с лингвистом | 10-15 |
| Отбор: словосочетания, минус-слова, подсветка найденного, проверка спорного моделью | 3-5 |
| Повторы и определение языка | 2-3 |
| Панель: источники, слова с показом форм, лента найденного, фильтры, выгрузка в Excel, уведомления | 7-10 |
| Разметка проверочного набора, замер качества, доводка | 5-7 |
| Выкладка, документация, передача | 3 |
| **Итого** | **56-87** |

**Просить: 4 месяца одного разработчика (около 85 рабочих дней).** Это
верхняя граница плюс небольшой запас: блокировки — та часть, где
сюрпризы находятся только при обходе живых сайтов, и заранее их не
посчитать.

**После запуска:** 2-4 дня в месяц на поддержку — сайты меняют вёрстку,
учётки упираются в ограничения, заказчик добавляет источники.

Если в объём всё-таки входят Facebook и Instagram — это отдельная строка
на 1-2 месяца без гарантии результата: всё упирается в то, дадут ли
доступ к Meta Content Library.

## Что нужно решить до старта

1. Список источников — с заказчиком и, для спорных изданий, с юристом.
2. Соцсети — входят или нет, и в каком виде.
3. Sputnik и другие санкционные источники — вопрос к донору.
4. Храним полный текст или только ссылку с фрагментом. Полный текст
   нужен для поиска; показывать наружу — вопрос авторского права.
5. Кто лингвист-консультант.
